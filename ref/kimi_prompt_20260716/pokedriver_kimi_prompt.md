# 宝可驾素材包 — Kimi K3 测试 Prompt

> 发给 Kimi K3 时，**同时上传 `pokedriver_assets.zip`**。

---

## Prompt 正文

```
你是一位有丰富创意的全栈游戏开发者。我提供一份素材包（已上传 pokedriver_assets.zip），请你基于它设计并实现一个完整的网页游戏。

## 素材内容

素材包里的文件和解压后的内容，你需要自己探索。解压命令：unzip pokedriver_assets.zip。先列出所有文件，逐个阅读理解数据结构。

### 必须使用素材
- 驾考题库（1034 题，中文科目一/四）
- 宝可梦数据库（721 只，含名称、稀有度、精灵图 base64）
- 配色体系和稀有度规则

### 游戏方向

** 交规Roguelike地牢（卡牌爬塔）**
Slay the Spire 风格。你是训练师，在地牢中前进。每个房间是一道交规题：答对出招攻击、答错挨打。击败宝可梦后可捕获加入队伍。稀有宝可梦是 BOSS。路径选择、道具商店（用答题获得的金币）。

### 技术建议
- 精灵图是 base64 格式，你可以根据此进行3D模型的创作
- Three.js
- 考虑移动端适配（触屏操作）

### 游戏必须包含
1. 开始/游戏核心/题库复习/图鉴/设置等页面
2. 核心玩法循环
3. 分数/进度显示
4. 使用所有宝可梦的精灵图
5. 游戏结束/结算画面
- 音效（用 Web Audio API 生成，不需要外部文件）
- 粒子特效
- 存档功能（localStorage）
- 连击/Combo 反馈
- 宝可梦图鉴收藏页

---

开始吧！
```
